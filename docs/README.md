# Repository organization

The [file map](file-map.json) records earlier repository paths and their current locations.
Memo numbers, titles, revision numbers, and published document contents remain unchanged.

`published_files` lists the former download addresses that the site build must preserve.
Each address receives the same file as its mapped replacement, including earlier PDF revisions.
`generated_assets` preserves the earlier stylesheet address after Jekyll compiles Sass.
Copies exist only in the built site; source documents have one maintained location in Git.

The [contribution guide](../CONTRIBUTING.md) explains how to add a revision and retain earlier links.
