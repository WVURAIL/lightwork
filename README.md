Use the [website](https://wvurail.org/lightwork/) to find guides by topic, watch videos, and download materials.

## Names and revisions

Ordinary files and folders use lowercase names with hyphens. Python files use underscores.
Memos use `memo-NNN-rN.pdf`, preserving the original memo and revision numbers.
An unnumbered revision stays unnumbered, such as `memo-031.pdf`.
Published titles, document contents, credits, and memo numbers remain unchanged.

The [file map](docs/file-map.json) records earlier paths and their replacements.
The site build preserves earlier download addresses without storing duplicate documents in the repository.

Follow the [contribution guide](CONTRIBUTING.md) to add a memo or update a revision.
The website and [memo index](memos/) use the same catalog in `_data/memos.yml`.

LightWork connects contributors building and studying radio telescopes: many hands make LightWork.
